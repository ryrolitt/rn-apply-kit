# profile/  (local only, never committed)

Filled by `/intake-profile` from your own documents, then your answers. Every fact carries its
source in brackets. `[CONFIRM: ...]` marks a gap for you to answer; Claude never fills one by
guessing. These five files are the only sources a letter or form answer may draw from.

Also here: `letterhead.txt`, the two lines every cover letter opens with, written at intake;
`scripts/check_package.py` compares each letter against it before an upload.
